<objective>
Replace Reverb's build-time browser credentials with request-time server injection (D-01), and turn `compose.dev.yml` from Laravel Sail's stock generated file into a purpose-built dev/test stack that builds this repository's own `Dockerfile` and ships every third-party service (D-03, D-04).

Purpose: today `resources/js/echo.js` reads Reverb's key, host, port and scheme from values Vite inlines at `pnpm run build` time. The published `ghcr.io/relaticle/relaticle:latest` image is built once in CI for every self-hoster, and each of them has a different domain and a different self-generated `REVERB_APP_KEY`, so there is no correct value to bake in. Chat message streaming is the core UX of `packages/Chat` and it is broken for every self-hoster today. This plan proves the fix end to end on a real containerized stack before any other file in the phase is touched.

Output: a Blade-rendered credential source in the Filament panel head, an `echo.js` that reads it, a rewritten `compose.dev.yml`, a regression test, and `.env.example` / `.env.ci` cleaned of the now-dead Vite build-time keys.

Scope note: running the Pest suite *inside* the container is deliberately not in scope. `.dockerignore` excludes `/tests` and the composer stage installs with `--no-dev`, so the built production image cannot run the suite. "Local tests" in the ROADMAP goal is satisfied by the stack building the real image and bringing up every backing service; the Pest suite stays on the native path per D-03.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| unauthenticated browser to app HTTP | The panel login page is public, and it now renders Reverb client credentials into its head |
| browser to reverb WebSocket | Any internet client can open a socket with the public app key and attempt channel subscriptions |
