    (1) Architecture section. Raise the container count in the sentence above the table to six, and add a `reverb` row to the table, keeping the existing column order and cell style. Image is `ghcr.io/relaticle/relaticle:latest`, purpose is the WebSocket server powered by Laravel Reverb that carries real-time chat message streaming.     (3) Environment variables. Add rows for `REVERB_APP_ID`, `REVERB_APP_KEY` and `REVERB_APP_SECRET` in the Required table, since `compose.yml` guards all three and the stack refuses to start without them. Mirror the existing `APP_KEY` row's style for telling the reader how to produce a value: these are operator-chosen secrets, so say to generate a random string for each and never reuse one across installs. Add the version caveat: live chat streaming needs an image built at or after this change, so an operator pinned to an older tag sees no streaming even with the reverb container healthy. This is the single most likely support question the change creates.

    (5) Reverse proxy. Extend all three existing subsections rather than adding a new section. For Nginx, show the extra location or server block that proxies the Reverb port with the `Upgrade` and `Connection` headers set and response buffering off, which is what a WebSocket upgrade requires. For Caddy, show the equivalent reverse proxy directive. For Traefik, extend the existing labels example with a router and service for the reverb container on its port. Keep each snippet at the same level of detail as the block it sits beside; this guide shows working fragments, not full configurations.

    (6) Container counts elsewhere. Raise the count in the Dokploy deploy step, which states how many containers it starts, and in the parallel Coolify sentence.
